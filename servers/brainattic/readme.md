# Brainattic

brainattic is a hosted knowledge base published by Finite Software Systems Ltd.
It exposes knowledge tools through a remote Streamable HTTP MCP endpoint.
Access follows the signed-in user's workspace permissions and rules.

Connect with OAuth authorization code, PKCE, metadata discovery, and dynamic
client registration. Complete browser sign-in and consent when Docker MCP
Toolkit requests authorization. A personal access token is not required.

The hosted application is proprietary; this entry contains only catalog metadata.

Docs: https://brainattic.ai/docs/connect
